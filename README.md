# 🧮 Simple Web Calculator

Aplikasi kalkulator berbasis web sederhana untuk melatih logika pemrograman dasar.

### 💡 Deskripsi
Proyek ini dibuat untuk melatih pemahaman saya tentang manipulasi DOM menggunakan JavaScript, menangani input tombol matematika, dan merancang antarmuka (*UI*) yang bersih menggunakan Tailwind CSS.

### 🛠️ Fitur & Teknologi:
- **Operasi Matematika Dasar** (penjumlahan, pengurangan, perkalian, dan pembagian)
- **Clear Display** (tombol reset angka)
- **HTML5, Tailwind CSS, & JavaScript**
